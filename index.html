Experiencia

Tengo experiencia participando en diversos proyectos universitarios, donde pude aplicar tanto habilidades técnicas como metodologías de trabajo colaborativo.

Uno de los proyectos más destacados fue una plataforma web para el alquiler de autos, desarrollada en colaboración con ocho grupos conformados por siete integrantes cada uno. En este proyecto trabajé principalmente en el frontend, utilizando Next.js, mientras que el backend se construyó con Express, Prisma y PostgreSQL, todo implementado con TypeScript.

En otro proyecto, desarrollamos una aplicación móvil utilizando React Native con Expo. También participé mayormente en el desarrollo del frontend, mientras que el backend fue desarrollado con Express, integrando Firebase para la autenticación. Este proyecto se implementó con JavaScript.

En ambos casos, se aplicó la metodología Scrum, lo que me permitió adquirir experiencia trabajando en equipo, organizando tareas en sprints y participando activamente en reuniones de seguimiento.
